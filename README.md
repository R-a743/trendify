# 🚀 Trendify - Modern E-Ticaret Arayüzü

Trendify, React kullanılarak geliştirilmiş, modern, hızlı ve kullanıcı dostu bir alışveriş deneyimi sunan bir web uygulamasıdır. Bu projede modern web standartları ve performanslı kodlama pratikleri ön planda tutulmuştur.

## 🌐 Canlı Demo
Projeyi canlı olarak buradan inceleyebilirsiniz: 
👉 [Trendify Canlı İzle](https://trendify-iota-seven.vercel.app)

## ✨ Özellikler
- **Responsive Tasarım:** Mobil, tablet ve masaüstü cihazlarla tam uyumlu.
- **Hızlı Performans:** React'in sanal DOM yapısı sayesinde akıcı geçişler.
- **Modern UI:** Kullanıcı odaklı, temiz ve şık arayüz bileşenleri.
- **Dinamik İçerik:** State yönetimi ile anlık güncellenen veriler.

## 🛠️ Kullanılan Teknolojiler
Bu proje geliştirilirken aşağıdaki teknolojiler ve kütüphaneler kullanılmıştır:

* **Framework:** [React](https://reactjs.org/)
* **Styling:** CSS3 / Module CSS
* **Deployment:** [Vercel](https://vercel.com/)
* **Versiyon Kontrol:** Git & GitHub
